Cómo llegan los datos de Percy a una pantalla de control

Open MCT es como el tablero de un auto, pero para naves espaciales: una página web donde la NASA arma pantallas con gráficas y tablas que muestran, en vivo, lo que le está pasando a una misión.

Las 5 piezas clave para conectar Percy

  1. Un plugin propio — una función install(openmct) que agrupa todo lo de Percy. Se enchufa igual que los demás (src/MCT.js:435; ejemplo de uso en index.html:104).
  2. Un tipo de objeto — “Sensor de Percy”, registrado con openmct.types.addType (src/api/types/TypeRegistry.js:59).
  3. Un proveedor de objetos y una carpeta raíz — para que aparezca “Perseverance” en el árbol de la izquierda con sus sensores (src/api/objects/ObjectAPI.js:168 y :498).
  4. Los metadatos — la lista de campos de cada dato: hora (eje X) y valor (eje Y). Modelo: example/generator/GeneratorMetadataProvider.js:73.
  5. El proveedor de telemetría — con request (historia) y subscribe (en vivo), registrado en src/api/telemetry/TelemetryAPI.js:167. Modelo: example/generator/GeneratorProvider.js:91 y :101.

La gráfica, las tablas y el reloj ya vienen incluidos (src/MCT.js:285–286): no hay que construirlos.

Cómo conectamos Percy

  1. Decidir la fuente de datos. Nuestra simulación de Marte (este proyecto, Three.js) ya “sabe” velocidad, posición, inclinación y batería del rover. Esa será la fuente.
  2. Hacer que la simulación hable. Que publique cada lectura, por ejemplo por un WebSocket, como { "id": "percy.velocidad", "utc": 1763300000000, "value": 0.04 }.
  3. Crear el plugin PercyPlugin con las piezas 2 a 5: 
    openmct.types.addType('percy.sensor', { name: 'Sensor de Percy' });
openmct.objects.addRoot({ namespace: 'percy', key: 'rover' });
openmct.objects.addProvider('percy', proveedorDeObjetos);
openmct.telemetry.addProvider({
  supportsRequest:   o => o.type === 'percy.sensor',
  request:           (o, opts) => historial(o, opts.start, opts.end),
  supportsSubscribe: o => o.type === 'percy.sensor',
  subscribe:         (o, avisar) => escucharWebSocket(o, avisar)
});
    Cada sensor declara sus campos: utc (hora, eje X) y value (eje Y).
  4. Enchufarlo en la página de Open MCT: openmct.install(PercyPlugin()), antes de openmct.start() (index.html:240).
  5. Armar la pantalla. En el árbol aparece “Perseverance”; al hacer clic en un sensor ya se ve su gráfica en vivo. Se pueden juntar varias en una gráfica apilada o en una tabla de “último valor” (LAD).
